BoatFlow explores a common connected-boat problem: useful systems such as lighting, electrical equipment, gas valves, alarms, heating, and battery monitoring are often controlled separately. Combining them into automated routines can feel like programming, which may discourage ordinary boat owners from using automation during important moments such as leaving the boat unattended.
The prototype tests the hypothesis that automation becomes easier and more trustworthy when it is presented as a simple “WHEN / DO / THEN” story. Owners select plain-language cards and toggles, see an immediate summary of what the boat will do, and receive confirmation as each safety step is completed. No programming syntax or technical configuration is shown.
BoatFlow contains four interactive screens: a boat-status home with one-tap modes, a no-code automation builder, a set of smart boating use cases, and a user-research evaluation form. The “Leaving the Boat” routine turns off lights and electrical equipment, closes the gas supply, activates the alarm, and sends a completion confirmation. All boat and evaluation data is deterministic and synthetic.
A potential study could involve 8–12 recreational boat owners with varied technical confidence. Researchers could measure task completion, time, errors, ease, whether the experience felt like programming, and willingness to use the feature. This prototype does not connect to real boat hardware or model device failures, permissions, poor connectivity, multiple users, emergency conditions, or other production safety requirements.
